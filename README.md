# 🌿 GreenShop – Modern E-Commerce Application

A high-performance, fully responsive e-commerce web application built with **Next.js**, **Tailwind CSS**, and modern front-end tooling. **GreenShop** provides a seamless online shopping experience, featuring authentication, dynamic product browsing, advanced form validation, and optimized UI components.

---

## 🚀 Key Features

- **Modern Framework (Next.js):** Built with App Router for speed, SEO, and optimization.
- **Authentication:** User authentication managed via Next-Auth.
- **Interactive UI:** Designed with Tailwind CSS v4 and Shadcn UI components.
- **Form Handling:** Managed by React Hook Form backed by Zod validation.
- **Carousels & Sliders:** Dynamic banners powered by Swiper.

---

## 🧰 Tech Stack

- **Framework:** Next.js (v16), React (v19)
- **Styling & UI:** Tailwind CSS v4, Shadcn UI, Base UI
- **Authentication:** Next-Auth
- **Forms & Validation:** React Hook Form, Zod
- **Icons & Sliders:** Swiper, Lucide React
- **Language:** TypeScript
